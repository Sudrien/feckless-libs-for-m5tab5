# The feckless ABI's storage section, version 2 (5003; version 1, 3008).
#
# What an app's ELF may take from a launcher that links the section's
# component, feckless_abi_storage -- one symbol a line, as exports.txt.
# The launcher defines the "@symbol"; an app that takes any name below
# refers to it (feckless_abi_require_storage()), so a launcher without
# the section refuses the app by that name instead of failing on the
# first file it opens. Lines that are not a bare name are ignored.
#
# Adding a name is compatible. Removing one, or changing what one means --
# a signature, a struct (FIL, FF_DIR and FILINFO are the app's, laid out
# by the FatFs configuration feckless_abi_storage pins) -- is a new
# section version. storage_v2 is version 1 with FatFs's fast seek on:
# FIL has a cltbl, so an app can build a cluster map (f_lseek() with
# CREATE_LINKMAP) and seek a large file without walking its FAT chain.
# Nothing else changed, but a v1 app's FIL is laid out without it.
@symbol feckless_abi_storage_v2
