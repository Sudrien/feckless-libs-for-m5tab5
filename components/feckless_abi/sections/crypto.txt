# The feckless ABI's crypto section, version 2 (8003, shrunk in 8007).
#
# What an app's ELF may take from a launcher that links the section's
# component, feckless_abi_crypto -- one symbol a line, as exports.txt.
# The launcher defines the "@symbol"; an app that takes any name below
# refers to it (feckless_abi_require_crypto()), so a launcher without the
# section refuses the app by that name instead of failing on its first
# hash. Lines that are not a bare name are ignored.
#
# It is hashing: a SHA-256 in one call. Keys, certificates and TLS are the
# launcher's -- it owns the device's HTTPS identity (feckless_https_*, in
# the network section), and an app never makes or holds a key. Version 1
# (8003) also listed the pk layer, the X.509 writer, key generation and
# PBKDF2 for an app that would make its own certificate; the one app that
# did (Defeatist) no longer does (its 8073), and PBKDF2 for a Wi-Fi PSK is
# wifi_psk() in the network handler. Nothing required version 1, so no
# launcher or app needs both.
#
# IDF 5.5 ships Mbed TLS 3.6 where IDF 6.1 ships 4.0, which moved the
# public surface: no sha256.h, hashes through PSA. The name an app takes
# depends on which it was built against, so a "@when mbedtls N" line
# starts the names that exist for that major only, until the next "@when"
# or an "@end"; the launcher's table lists its own major's, and the build
# check accepts either. Each major has a marker symbol that only a
# launcher of that major defines, and feckless_abi_require_crypto() refers
# to the app's, so an app built for the other one fails in
# esp_elf_relocate() naming it and not a function.
#
# Adding a name is compatible. Removing one, or changing what one means,
# is a new section version: crypto_v3.
@symbol feckless_abi_crypto_v2

# ---- Mbed TLS 3.6 (IDF 5.x) -------------------------------------------
@when mbedtls 3
feckless_abi_crypto_mbedtls3
mbedtls_sha256
@end

# ---- Mbed TLS 4.0 (IDF 6.x) -------------------------------------------
# psa_crypto_init() may be called again, so an app that cannot know
# whether the launcher has called it may; the launcher's TLS has.
@when mbedtls 4
feckless_abi_crypto_mbedtls4
psa_crypto_init
psa_hash_compute
@end
