# The feckless ABI's network section, version 1 (6004).
#
# What an app's ELF may take from a launcher that links the section's
# component, feckless_abi_network -- one symbol a line, as exports.txt.
# The launcher defines the "@symbol"; an app that takes any name below
# refers to it (feckless_abi_require_network()), so a launcher without
# the section refuses the app by that name instead of failing on its
# first connection. Lines that are not a bare name are ignored.
#
# Several structs below are laid out by the configuration -- httpd_req_t's
# uri by CONFIG_HTTPD_MAX_URI_LEN, httpd_uri_t by the WebSocket options,
# esp_http_client_config_t by the TLS ones, sockaddr_storage by IPv6 --
# so feckless_abi_network holds both sides to one configuration. Adding a
# name is compatible. Removing one, or changing what one means or that
# configuration, is a new section version: network_v2.
@symbol feckless_abi_network_v1
