# The feckless ABI's box marker, version 1 (u-feckless-0005).
#
# A boxed app's imports are the core list's and the other sections', less
# what it must link in itself (feckless_box_libc's inapp.txt), and the names
# below, which only a box answers. The symbol says the ELF is built for a box -- an app that
# refers to it (feckless_abi_require_box()) is refused by name by a launcher
# with no box, and recognised by one that has. No component of this repository
# defines it for a trusted run, on purpose.
@symbol feckless_abi_box_v1

# u-feckless-0006: the log line feckless_box_libc's esp_log() formats in
# the app and hands over as two strings.
feckless_box_log

# u-feckless-0049: the box heap's figures, which feckless_box_libc's
# heap_caps_get_info() and its siblings ask for (u-feckless-0048).
feckless_box_heap_stats

# u-feckless-0075: callbacks into the app. feckless_box_libc's constructor
# says where the app's loop is; the loop asks for each call and answers it.
feckless_box_upcall_loop_is
feckless_box_upcall_next

# u-feckless-0076: the interfaces one by one, as numbers, for
# feckless_box_libc's esp_netif_find_if().
feckless_box_netif_next

# u-feckless-0082: the launcher's own heap by capability, which
# feckless_box_libc's heap_caps_get_info() and its siblings answer for
# internal and DMA memory.
feckless_box_host_heap
# u-feckless-0083: the app's network hooks, asked in the app by
# feckless_box_libc's feckless_net_set_hooks() and its wifi_apply_settings(),
# wifi_request_apply() and wifi_request_restart(), and handed over as
# answers with the request; the notes by address, for the callback loop.
feckless_box_net_hooks
feckless_box_wifi_apply
