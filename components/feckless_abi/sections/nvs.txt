# The feckless ABI's nvs section, version 1 (4004).
#
# What an app's ELF may take from a launcher that links the section's
# component, feckless_abi_nvs -- one symbol a line, as exports.txt. The
# launcher defines the "@symbol"; an app that takes any name below
# refers to it (feckless_abi_require_nvs()), so a launcher without the
# section refuses the app by that name instead of failing on its first
# save. Lines that are not a bare name are ignored.
#
# Adding a name is compatible. Removing one, or changing what one means,
# is a new section version: nvs_v2.
@symbol feckless_abi_nvs_v1
