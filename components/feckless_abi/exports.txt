# The feckless ABI, version 1 (FECKLESS_ABI_VERSION in feckless_abi.h).
#
# What an app's ELF may leave undefined for the launcher to supply: one
# symbol a line, by section. The launcher's table is generated from this
# file; an app's ELF is checked against it. Lines that are not a bare
# name are ignored.
#
# Adding a name is compatible: apps built against v1 still load. Removing
# one, or changing what one means -- its signature, a struct it takes --
# is a new version: bump FECKLESS_ABI_VERSION and FECKLESS_ABI_SYMBOL
# together.
